# Smart Home Monitoring & Control System

## Overview

The Smart Home Monitoring & Control System is a cloud-connected IoT-based application designed to allow users to remotely monitor and control smart home devices through a mobile application. The system consists of an Android mobile client, a Firebase cloud backend, and a web-based hardware simulator that represents real-world smart home devices.

The application provides real-time device status monitoring, remote control capabilities, automated safety mechanisms, and usage analytics to improve home convenience, security, and safety.

## Key Features

- 🏠 Multi-floor smart home dashboard with interactive floor layouts
- 💡 Real-time monitoring and control of smart devices
- 🔌 Support for different device profiles:
    - Smart lighting systems
    - Power outlets
    - Multi-switch units
    - Safety-critical appliances (e.g., irons)
    - Security cameras
- ☁️ Cloud-based real-time synchronization using Firebase
- 🔥 Automated safety rules for preventing device hazards
- 🔔 Notification alerts for important system events
- 📊 Device usage tracking and reporting
- 🖥️ Web-based hardware simulator for IoT device visualization
